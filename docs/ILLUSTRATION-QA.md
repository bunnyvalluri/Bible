# 🛡️ Vachanam Illustration Quality Assurance (QA)

Every generated illustration must pass a 4-dimensional QA rubric before approval:

| QA Dimension | Threshold | Criteria |
| :--- | :--- | :--- |
| **Content QA** | ≥ 0.90 | Accurate scripture theme, non-distorted theological meaning, contextually grounded. |
| **Style QA** | ≥ 0.90 | 16:9 aspect ratio, clean editorial hand-drawn aesthetic, uncluttered negative space. |
| **Safety QA** | 1.00 (Strict) | Zero mockery, no offensive religious imagery, reverent depiction of biblical figures. |
| **Accuracy QA** | ≥ 0.90 | Clean typography integration, correct book/chapter/verse citation. |
