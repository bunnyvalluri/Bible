# Image Quality Assurance (QA) Engine

## Overview
Every Bible illustration generated by ComfyUI or Diffusers must pass automated multi-stage Quality Assurance checks before publishing.

---

## 1. Automated Verification Checks

1. **Byte & Decodability Verification**: Checks if image file is valid, non-truncated, and decodable.
2. **Aspect Ratio Check**: Validates 16:9 ratio within a tolerance threshold (rejects distorted 1:1 or 9:16 outputs).
3. **Blank / Void Detection**: Calculates standard deviation of pixel color distributions (flags solid black or white frames).
4. **Contrast & Dynamic Range**: Verifies color spectrum depth across Levantine earth tones and volumetric lighting.
5. **Safety & Artifact Verification**: Checks against distorted anatomy, modern text on canvas, and watermark patterns.
